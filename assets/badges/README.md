# Profile badges

Static SVG badges generated with [Shields badge-maker](https://github.com/badges/shields/tree/master/badge-maker) 6.0.0 and [Simple Icons](https://github.com/simple-icons/simple-icons) 16.35.0. They are served directly from this repository and require no running service.

The centered introduction, contact buttons, and compact technology badges are inspired by [aCodeDog's profile](https://github.com/aCodeDog/aCodeDog). Biography and project descriptions refer to Kwon Taek Ju's own work.
