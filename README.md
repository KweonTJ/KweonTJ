# Hi, I'm Taek Ju.

I develop robotic systems **from simulation to real hardware**, connecting robot control, reinforcement learning, and 3D perception.

My work centers on **ROS 2**, **quadruped locomotion**, and **autonomous mobile robots** — from learning how a robot moves to integrating the systems that let it act in the real world.

## Selected Projects

### 01 &nbsp; Control the robot
#### [Unitree Go2 · ROS 2 Control ↗](https://github.com/KweonTJ/Unitree_Go2_ROS2_Control)

A bridge between standard ROS 2 commands and real quadruped hardware.

- **Command flow:** `geometry_msgs/Twist` → Go2 Sport API
- **Applications:** real-robot control and keyboard teleoperation

<sub>ROS 2 &nbsp; / &nbsp; Unitree Go2 &nbsp; / &nbsp; Robot Control</sub>

---

### 02 &nbsp; Learn to move
#### [HIMLoco Horizontal ↗](https://github.com/KweonTJ/HIMLoco_Horizontal)

Reinforcement-learning locomotion research for Unitree Go2, based on HIMLoco.

- **Research focus:** stable traversal and reduced body motion over uneven terrain
- **Direction:** path tracking and sim-to-real deployment

<sub>Reinforcement Learning &nbsp; / &nbsp; Quadruped Locomotion &nbsp; / &nbsp; Sim-to-Real</sub>

---

### 03 &nbsp; Perceive and act
#### [3D Perception · Mobile Manipulator ↗](https://github.com/KweonTJ/3D_pereception_Based_Mobile_Manipulator-Autonomous_Navigation_System)

A ROS 2 system connecting spatial perception, manipulation, and autonomous navigation.

- **Perception to action:** RGB-D sensing → 3D position estimation → OpenManipulator-X control
- **Integration:** autonomous navigation and multi-robot cooperation

<sub>3D Perception &nbsp; / &nbsp; Mobile Manipulation &nbsp; / &nbsp; Autonomous Navigation</sub>
