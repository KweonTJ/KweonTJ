**Robotics Engineer · Robot Learning & Autonomous Systems**

I connect **learning-based control, 3D perception, and hardware** to build legged robots, mobile manipulators, and autonomous systems.

My work spans **Go2 locomotion, OpenMANIPULATOR-X manipulation, and Jetson-based rescue mapping**, with projects covering policy training, ROS integration, and embedded control.

**Contact** · [cbnuai@chungbuk.ac.kr](mailto:cbnuai@chungbuk.ac.kr)

## Selected work

| Project | Focus |
| :--- | :--- |
