**Robotics Engineer · Robot Learning & Autonomous Systems**

I connect **learning-based control, 3D perception, and hardware** to build legged robots, mobile manipulators, and autonomous systems.

My work spans **Go2 locomotion, OpenMANIPULATOR-X manipulation, and Jetson-based rescue mapping**, with projects covering policy training, ROS integration, and embedded control.

**Contact** · [cbnuai@chungbuk.ac.kr](mailto:cbnuai@chungbuk.ac.kr)

## Selected work

| Project | Focus |
| :--- | :--- |
| **[Go2 locomotion](https://github.com/KweonTJ/HIMLoco_Horizontal)** | Reinforcement learning for uneven terrain, with body-motion and path-tracking evaluation in Isaac Gym. |
| **[OMX learning](https://github.com/KweonTJ/omx_train_ws)** · [Runtime](https://github.com/KweonTJ/Omx_Turtle_Bot) | PPO residual control in MuJoCo, connected to ArUco perception and ROS 2 pick-and-place runtimes. |
| **[3D mobile manipulation](https://github.com/KweonTJ/3D_pereception_Based_Mobile_Manipulator-Autonomous_Navigation_System)** | RGB-D localization and coordinate transforms for manipulation, with TurtleBot3 leader–follower transport. |
| **[AI Rescue Box](https://github.com/KweonTJ/AI_Rescue_Box)** | Floor-plan alignment, RGB-D SLAM, and person detection on Jetson, with UWB messaging and rescue-map interfaces. |
| **[Dual Arm](https://github.com/KweonTJ/Dual_Arm)** · [ORV 4WD](https://github.com/KweonTJ/ORV_4WD) | AX-12A dual-arm modeling and a four-wheel rover: physics simulation, joint control, encoder/PID firmware, and monitoring. |
| **[MORAI driving](https://github.com/KweonTJ/MORAI_Simulation)** · [CAN](https://github.com/KweonTJ/CAN_Protocol) | Pure Pursuit and PID driving control, LiDAR obstacle perception, traffic-light detection, and CAN/DBC communication. |
